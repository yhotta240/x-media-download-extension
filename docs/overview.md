## 説明

X Media Downloadは，Xのポストに含まれる画像・動画をワンクリックで保存するためのChrome拡張機能です．

## 現在のバージョン

0.0.1は開発準備版です．名称・バージョン・対象サイトなどの初期設定を整理しています．メディア検出・ダウンロード機能は未実装です．

## 対象と方針

- 対象サイトは `https://x.com/*`，対象ブラウザはGoogle Chromeです．
- Popupは設定画面として使用します．設定項目は今後確定します．
- 外部の独自サーバーは使用しません．
